## 1. 快速开始（5分钟）

### 假设前提

- ✓ Radxa ROCK 3B已安装，蓝牙模块已启用
- ✓ 雷神蓝牙手柄已配对到ROCK 3B
- ✓ ROS2和相关驱动已安装
- ✓ 已编译visual_following_car包

### 一行命令启动

```bash
cd ~/MyDroid/ros2_ws
source install/setup.bash
ros2 launch visual_following_car bluetooth_teleop.launch.py
```

此时你应该能用蓝牙手柄控制底盘：

- **左摇杆**: 控制底盘运动（上前进，下后退，左左移，右右移）
- **右摇杆**: 控制底盘旋转（左逆时针，右顺时针）
- **D-Pad**: 控制云台Pan角度（←左，→右）
- **Start**: 启用自动视觉跟随
- **Back**: 禁用自动视觉跟随
- **Y键**: 紧急停止

## 2. 详细步骤（30分钟）

### 第1步: 确认蓝牙硬件就绪

```bash
# 检查蓝牙服务
sudo systemctl status bluetooth
# 应该显示 "active (running)"

# 检查蓝牙设备
hciconfig
# 应该显示 "UP RUNNING"

# 初始化蓝牙（如需要）
~/init_bluetooth.sh
```

### 第2步: 确认手柄已配对

```bash
# 查看已配对设备
sudo bluetoothctl paired-devices

# 输出示例:
# Device 5C:F3:70:8A:XX:XX Thunderobot_Gamepad
# Device XX:XX:XX:XX:XX:XX SomeOtherDevice

# 如果没看到你的手柄，需要先配对：
sudo bluetoothctl
> scan on
# 让手柄进入配对模式（通常是长按HOME键）
> pair 5C:F3:70:8A:XX:XX
> trust 5C:F3:70:8A:XX:XX
> connect 5C:F3:70:8A:XX:XX
> quit
```

### 第3步: 自动连接手柄（可选）

```bash
# 创建自动连接脚本
cat > ~/connect_gamepad.sh << 'EOF'
#!/bin/bash
sudo bluetoothctl connect 5C:F3:70:8A:XX:XX
sleep 2
sudo bluetoothctl info 5C:F3:70:8A:XX:XX | grep "Connected"
EOF

chmod +x ~/connect_gamepad.sh

# 使用
~/connect_gamepad.sh
```

### 第4步: 启动Joy节点（测试输入）

在终端1运行：
```bash
cd ~/MyDroid/ros2_ws
source install/setup.bash
ros2 run joy joy_node
```

在终端2检查Joy消息：
```bash
ros2 topic echo /joy
```

**预期**: 当你按动手柄上的按键时，应该看到json格式的消息更新

### 第5步: 启动蓝牙手柄处理节点

```bash
# 终端1: 启动Joy节点
ros2 run joy joy_node

# 终端2: 启动蓝牙手柄处理节点
ros2 run visual_following_car bluetooth_gamepad_node --ros-args --log-level debug

# 终端3: 监听速度命令
ros2 topic echo /cmd_vel
```

**预期**: 移动左摇杆时，应该看到 `/cmd_vel` 输出速度包含 `linear.x` 和 `linear.y`

### 第6步: 启动完整系统

```bash
# 一条命令启动所有节点
ros2 launch visual_following_car bluetooth_teleop.launch.py

# 此时应该能用手柄控制底盘和云台
```

## 3. 适配你的手柄（10-20分钟）

### 场景A: 标准Gamepad（Xbox/PS4兼容）

通常无需修改，默认配置应该可用。

### 场景B: 雷神蓝牙手柄映射不匹配

#### 步骤1: 运行映射检测工具

```bash
cd ~/MyDroid/ros2_ws
source install/setup.bash

# 终端1: 启动Joy节点
ros2 run joy joy_node

# 终端2: 运行映射检测
python3 src/visual_following_car/visual_following_car/detect_gamepad_mapping.py
```

#### 步骤2: 逐一测试按键

按照工具的提示，按下手柄上的每一个按键：

```
按下手柄的：
1. A按键  (通常是蓝色，X shaped)
2. B按键  (红色，O shaped)
3. X按键  (黄色，Square shaped)
4. Y按键  (绿色，Triangle shaped)
5. LB按键 (左肩)
6. RB按键 (右肩)
7. Back按键
8. Start按键
9. 左摇杆点击
10. 右摇杆点击
11. HOME/Guide按键
```

#### 步骤3: 逐一测试摇杆和轴

```
移动以下各个轴：
1. 左摇杆 - 上下左右
2. 右摇杆 - 上下左右
3. 左触发器 - 从不按 到 完全按下
4. 右触发器 - 从不按 到 完全按下
5. D-Pad (方向键) - 上下左右
```

#### 步骤4: 生成映射配置

检测工具会输出一个汇总，例如：

```
按键映射:
  0 → A
  1 → B
  2 → X
  3 → Y
  4 → LB
  5 → RB
  6 → Back
  7 → Start
  8 → LS
  9 → RS
  10 → Guide

轴映射:
  0 → LX
  1 → LY
  2 → LT
  3 → RX
  4 → RY
  5 → RT
  6 → DX
  7 → DY
```

#### 步骤5: 更新配置文件

根据检测结果，修改 `config/gamepad_mapping.yaml`：

```yaml
gamepad_mapping:
  buttons:
    A:      0   # 根据检测结果修改
    B:      1
    X:      2
    Y:      3
    LB:     4
    RB:     5
    back:   6
    start:  7
    left_stick:   8
    right_stick:  9
    guide:  10

  axes:
    left_stick_x:   0
    left_stick_y:   1
    left_trigger:   2
    right_stick_x:  3
    right_stick_y:  4
    right_trigger:  5
    dpad_x:  6
    dpad_y:  7
```

#### 步骤6: 重新编译和重启

```bash
cd ~/MyDroid/ros2_ws
colcon build --packages-select visual_following_car
source install/setup.bash

# 重启节点，新的映射会被加载
ros2 launch visual_following_car bluetooth_teleop.launch.py
```

### 场景C: 某些控制反向了

如果摇杆方向反了，你有两个选择：

**选项1**: 物理上交换接线（如果可能）

**选项2**: 在代码中反转

编辑 `bluetooth_gamepad_node.py` 中的 `_handle_chassis_control()` 函数：

```python
# 原来
forward = msg.axes[forward_axis]

# 改为反向
forward = -msg.axes[forward_axis]  # 前后反向

# 同样可以反转其他轴
strafe = -msg.axes[strafe_axis]    # 左右反向
rotate = -msg.axes[rotate_axis]    # 旋转反向
```

然后重新编译：
```bash
cd ~/MyDroid/ros2_ws
colcon build --packages-select visual_following_car
```

### 场景D: 触发器值范围异常

如果触发器的值不是 0~1 而是其他范围，可能需要映射：

```python
# 在 bluetooth_gamepad_node.py 中修改

def _normalize_trigger(self, raw_value: float) -> float:
    """标准化触发器值到 0~1 范围"""
    
    # 如果触发器范围是 -1~1，转换为 0~1
    if raw_value < -0.5:
        return 0.0
    elif raw_value > 0.5:
        return 1.0
    else:
        return (raw_value + 1.0) / 2.0
    
    # 或直接简单映射
    # return max(0, min(1, (raw_value + 1) / 2))
```

## 4. 故障排查

### 问题1: "找不到Joy节点"

**症状**: `ros2 run joy joy_node` 报错：`package not found`

**解决**:
```bash
# 方法1: 安装官方包
sudo apt-get install ros-humble-joy

# 方法2: 从源码编译
cd ~/MyDroid/ros2_ws/src
git clone https://github.com/ros-drivers/joystick_drivers.git
cd ..
colcon build --packages-select joy
```

### 问题2: "手柄无输入"

**症状**: Joy节点运行但 `/joy` 话题没有更新

**诊断步骤**:
```bash
# 检查设备是否存在
ls /dev/input/js*
# 如果出现 /dev/input/js0, /dev/input/js1 等，说明设备存在

# 检查权限
ls -l /dev/input/js*
# 如果只有 root 或特定用户能读，需要修改权限

# 修改权限
sudo chmod a+r /dev/input/js*
```

### 问题3: "按键映射错乱"

**症状**: 按A键却发送了B键的命令

**解决**:
1. 运行 `python3 detect_gamepad_mapping.py` 重新检测
2. 更新 `config/gamepad_mapping.yaml`
3. 重启节点

### 问题4: "蓝牙频繁断连"

**症状**: 手柄连接一会儿就断开

**可能原因**:
- 蓝牙信号干扰（WiFi同频）
- 距离太远
- 手柄电池不足

**解决**:
```bash
# 方法1: 靠近ROCK 3B（< 3米）
# 方法2: 避免WiFi干扰（2.4GHz和5GHz选择）
# 方法3: 更换手柄电池
# 方法4: 重启蓝牙
sudo systemctl restart bluetooth
```

### 问题5: "蓝牙手柄节点收不到消息"

**症状**: `bluetooth_gamepad_node` 启动后没有任何输出

**诊断**:
```bash
# 检查Joy节点是否运行
ros2 node list | grep joy

# 检查Joy消息
ros2 topic echo /joy --once

# 检查蓝牙节点是否启动
ros2 node list | grep bluetooth
```

**解决**: 确保Joy节点先启动，然后再启动蓝牙手柄节点

## 5. 完整系统集成

### 第1阶段: 蓝牙+手柄测试（10分钟）

```bash
# 仅测试蓝牙手柄输入，不涉及电机
ros2 launch visual_following_car bluetooth_teleop.launch.py

# 监听速度命令
ros2 topic echo /cmd_vel

# 期望: 移动摇杆时有对应的速度输出
```

### 第2阶段: 视觉+蓝牙手动控制（15分钟）

```bash
# 启动蓝牙手柄控制（不启用自动跟随）
ros2 launch visual_following_car bluetooth_teleop.launch.py

# 用手柄操纵底盘
# 左摇杆: 底盘运动
# Start: 启用自动跟随
# 摄像头会跟踪人物运动
```

### 第3阶段: 完整视觉跟随（可选）

```bash
# 若要启用视觉自动跟随，启动完整系统
ros2 launch visual_following_car bringup.launch.py

# 此时：
# - 蓝牙手柄可随时手动控制
# - 按Start键启动自动跟随
# - 按Back键人工接管
```

### 集成检查清单

```
蓝牙部分:
□ 手柄能配对到ROCK 3B
□ Joy节点能输出 /joy 消息
□ bluetooth_gamepad_node 正确加载映射

ROS2消息链:
□ /joy 话题有实时更新
□ /cmd_vel 有对应的速度输出
□ /gimbal/pan_angle 有云台角度输出

硬件执行:
□ serial_bridge_node 正确发送UART帧
□ STM32正确接收和解析
□ 电机根据手柄输入运动

功能测试:
□ 左摇杆控制底盘运动✓
□ 右摇杆控制底盘旋转 ✓
□ D-Pad控制云台Pan角 ✓
□ Start/Back键切换模式 ✓
□ Y键紧急停止运行 ✓
```
